Step 3 · Generate and edit

The generator writes one section per task, follows your format profile and rubric from Settings, and cites only real, well known published sources in APA style.

No Anthropic API key yet. Generation uses the Muse API from Anthropic, with your own key:
  1. Open the Claude Console and sign in (or create an account).
  2. Open API Keys, click Create Key, and copy the key.
  3. Open Settings (top right), paste it into the Anthropic API key field, and come back here.
Note: the Muse API is a paid developer API. It is separate from a Claude subscription, and your Console account needs credit on it before generation will run.
The key is stored only in this browser (localStorage). It is never sent anywhere except to Anthropic when you generate.

Google Docs and Classroom

One time Google setup. The Google buttons need your own free OAuth Client ID:
  1. Open the Google Cloud Console credentials page, create a project if asked.
  2. Enable the Google Drive API and Google Classroom API for that project.
  3. Create an OAuth client ID of type Web application. Under Authorized JavaScript origins, add the address this page is opened from (for a local file it is shown as null origin, so host the page on any static site, for example GitHub Pages, and add that origin).
  4. Copy the Client ID into Settings, then use Connect Google below.

School format profile

Prefilled with the NMA College format. Update these values here any time your school format changes, and every export follows the new profile.

Cover page

School cover page pattern: a bold module line, a two column Submitted to and Submitted by block, a centered cohort line such as L-4 B-24 On Campus, and a centered Date of Submitted line. A brief's own instructions always override this sample format.

Scoring rubric

Prefilled with the real NMA College marking rules from the BBA Program Academic Writing class. The generator writes to score well against this rubric; edit it any time your school scheme changes.
